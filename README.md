# Outreach CRM

A minimal, single-file CRM for Instagram DM outreach. Open `index.html` in a browser.

- **Home** – DMs sent, replies, response rate, calls booked, and which message works best.
- **Leads** – paste IG profile links or @handles. Each lead moves forward with one tap: Send → Got reply → Booked call.
- **Messages** – your DM versions. They take turns so each gets a fair test; once one wins, tap **Improve** to write a new version.

Data is saved in your browser. Use **Backup & settings** on Home to download or load a backup.
